# mypage

This repository now contains a Next.js + Tailwind personal site for `ts19u`.

Quick start

1. Install dependencies:

```
npm install
```

2. Run dev server:

```
npm run dev
```

Open http://localhost:3000

Notes
- Tailwind is configured in `tailwind.config.js` and imported in `styles/globals.css`.
- Update `pages/index.js` with your real project links and contact info.
